Contexto y objetivo

Un ejercicio de React sirve para estudiar un flujo completo de creación, edición, búsqueda y eliminación. El reto es que la persistencia del navegador falle de manera comprensible y que el estado de edición siga siendo coherente con la lista. La demo no necesita cuentas ni un backend.

Decisiones de estado y persistencia

La lista se guarda como JSON en localStorage. Al recuperarla se comprueba tanto el análisis del JSON como su estructura. El almacenamiento puede estar bloqueado o sin espacio; el código comunica esa condición y permite continuar usando la interfaz. Al borrar una tarea que estaba en edición se abandona esa edición para no mantener una referencia inválida.

Pruebas y experiencia de uso

Los controles de completar utilizan un checkbox nativo. Las pruebas verifican listas válidas, datos incompatibles y errores de almacenamiento. La integración continua ejecuta lint, pruebas y compilación antes de publicar la demo. La captura incluye una tarea ficticia creada solo para mostrar la interfaz.

Alcance y siguientes mejoras

La persistencia pertenece al navegador y origen actuales: no existe sincronización entre dispositivos. El repositorio conserva las instrucciones de instalación. Las mejoras de recuperación y documentación se realizaron con ayuda de IA. Una evolución con cuentas requeriría definir backend, permisos y estrategia de sincronización como un alcance nuevo.
