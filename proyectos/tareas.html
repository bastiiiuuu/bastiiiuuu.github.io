PROYECTO Y DECISIONES

Gestor de tareas

Un ejercicio pequeño para practicar estado, persistencia y recuperación ante fallos.

Qué permite hacer

Crear, editar, completar, buscar y eliminar tareas. Los datos se guardan en localStorage y se recuperan al abrir el mismo navegador.

El detalle que cambia la experiencia

Un JSON corrupto o una estructura incompatible no debe impedir abrir la aplicación. El almacenamiento se valida y sus errores se comunican. Si una tarea se elimina mientras se edita, se cancela esa edición para evitar perder el siguiente envío.

Accesibilidad y comprobaciones

Las tareas se completan con un checkbox nativo, operable con teclado. Tres pruebas verifican recuperación de listas válidas, datos inválidos y almacenamiento bloqueado. La compilación y ESLint forman parte de la verificación previa a la demo.

Límites

No hay cuentas ni backend. La lista pertenece al navegador y no se sincroniza entre dispositivos. Las mejoras se prepararon con asistencia de IA.
