SmartAttendance 360

Asistencia, gestión laboral y apoyo a emergencias mediante IoT.

Estado actual

Proyecto en desarrollo. El mecanismo físico está preparado, según lo confirmado por su autor. La integración completa con web, backend y aplicación móvil continúa en desarrollo; esta página no ofrece una demostración de un sistema terminado.

Participación

Trabajo en equipo con participación compartida en hardware, plataforma web, backend y aplicación móvil. Los modelos de datos, endpoints y mecanismos de autenticación deben coordinarse entre ambos integrantes.

Hardware previsto

Arduino UNO R4 WiFi, lector RFID RC522, tarjetas o llaveros, LCD 16×2 con I2C, buzzer y LEDs de estado. El diseño contempla adaptación de niveles lógicos para el lector y almacenamiento temporal de registros ante pérdida de conectividad.

Arquitectura prevista

Arduino y RFID
Web administrativa
App de trabajadores
API central y validación de permisosBase de datos PostgreSQL

El dispositivo, la web y la aplicación móvil compartirán un backend y una base de datos. La aplicación móvil no se conectará directamente a Arduino ni a la base. Durante el desarrollo podrá trabajar con datos simulados, manteniendo preparada la capa de servicios para la API real.

Tecnologías propuestas

C++ para Arduino, Flutter y Dart para móvil, React para web, Node.js y Express para el backend, PostgreSQL, API REST con HTTPS, WebSockets, JWT y Firebase Cloud Messaging. Son decisiones propuestas del proyecto; no se presentan aquí como tecnologías ya implementadas o dominadas.

Alcance del producto

Se prevén registro de entradas y salidas, administración de trabajadores y tarjetas, turnos, historial, estadísticas, justificaciones y notificaciones. El modo emergencia utilizará los registros para estimar quién podría encontrarse dentro de las instalaciones y permitir confirmaciones de zona segura.

El modo emergencia es un apoyo a los procedimientos oficiales, no una garantía de localización ni un reemplazo del protocolo de evacuación.
