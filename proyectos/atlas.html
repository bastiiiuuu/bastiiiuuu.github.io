PROYECTO Y DECISIONES

Atlas de anatomía 3D

Un proyecto con apoyo de IA para explorar modelos y estudiar visualización en el navegador.

Qué contiene

Un visor anatómico con Three.js, selección de estructuras, aislamiento, búsqueda y fichas. La edición pública utiliza modelos GLB y catálogos estáticos; una edición local añade FastAPI.

Cómo se organiza

Un exportador Python prepara los datos para GitHub Pages. El navegador carga las capas que necesita y puede consultar Wikipedia. Los workers trasladan parte de la preparación de geometría fuera del hilo de interfaz.

Transparencia sobre el proyecto

El desarrollo contó con apoyo de IA. La presencia de técnicas avanzadas en el código no se presenta como prueba de dominio individual de todas ellas. Los modelos proceden de terceros y conservan sus licencias.

Qué se puede verificar

El repositorio incluye veintisiete pruebas Python de búsqueda, identidad de estructuras, exportación estática y otros contratos. Hay herramientas adicionales de navegador. Un resultado de pruebas no certifica precisión clínica ni un rendimiento universal en todos los dispositivos.

Recorrido sugerido

Buscar una estructura, aislarla, restaurar el contexto y explorar una ficha. Revisar después el diagrama y las instrucciones para distinguir qué ejecuta el navegador y qué pertenece a la versión local.
